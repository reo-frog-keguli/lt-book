# 無駄を生まないAI活用法 — LT資料

机の上の一冊の本をめくりながら進む、ライトニングトーク用のWebスライドです。
パワポ風の画面からカメラが引き、本が開き、見開きごとに水槽・星図・設計図・積み木の城などの世界に切り替わります。

## 見られる環境

- **PCの Chrome 157 以降**（HTML-in-Canvas を使っています）。それ以外のブラウザでは案内だけが表示されます
- 初回は3Dモデル（約43MB）の読み込みに少し時間がかかります

## 操作

| 操作 | 動き |
|---|---|
| Space / → / Enter / PageDown | 次へ（演出中にもう一度押すと最後まで飛ばす） |
| R | 最初から |
| マウス移動 | 本を見る角度を変える |
| Shift を押しながらマウス移動 | カメラを止めたまま、カーソルの効果だけを動かす |
| ホイール | 寄る・引く（`0` キーで戻す） |
| クリック | 設計図の部品を押す・便箋をつかむ |

`?step=番号` を付けて開くと、その場面まで早送りします（例：`?step=10`）。

## 手元で動かす

```bash
npm install
npm run dev
```

`http://localhost:5183/` を Chrome で開きます。

## 文字を直すとき

ページの文字はほぼすべて `index.html` にあります（層ごとに `id="L_s3h"` などで分かれています）。
文字の大きさや位置は `src/style.css` です。

## 使っているもの

- [three.js](https://threejs.org/)、[Vite](https://vite.dev/)
- フォント：Shippori Mincho、Cormorant Garamond、Zen Kurenaido（@fontsource 経由、いずれも OFL）
- 3Dモデル（錦鯉・蓮・睡蓮の葉・ロボット・積み木の城・巻物・プラグ・パズルピース）は [Meshy](https://www.meshy.ai/) で生成
- 本・机・紙面・水面・星空などはコードで描画
